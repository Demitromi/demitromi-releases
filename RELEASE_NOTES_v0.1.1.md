# DEMITROMI Founder Preview 0.1.1

This is the first invite-only DEMITROMI Founder Preview release prepared for external founder testing.

## What is included

- Compose PDF workflow
- PDF open/view
- combine and reorder
- page rotate, duplicate, and remove
- Fill & Sign document marking
- PDF compression
- save-as-new-copy safety model
- local Recent activity
- first-launch Founder Preview Terms and Privacy acceptance
- signed Windows x64 MSIX
- Windows App Installer update metadata

## Qualification

The release candidate passed the project's current automated and integration verification, including:

- 26/26 self-tests
- 10/10 navigation tests
- 22/22 Recent Activity tests
- 23/23 worker integration tests
- 84/84 PDF corpus cases with zero changed source documents
- 4/4 compression validation cases

The signed final package also passed an in-place signed 0.1.0.0 to 0.1.1.0 update with retained local state, packaged Compose open/edit/save, and uninstall/reinstall testing.

See [Known Limitations](KNOWN_LIMITATIONS.md).
