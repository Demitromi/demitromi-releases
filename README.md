# DEMITROMI Founder Preview

**DEMITROMI — your computer. smarter.**

This repository is the official distribution surface for the invite-only DEMITROMI Founder Preview for Windows x64.

## Current release

**Founder Preview 0.1.1**

DEMITROMI currently centers on **Compose**, a local-first PDF workflow for opening, combining, reordering, rotating, duplicating, removing, filling/signing, compressing, and saving documents as new copies.

The Founder Preview is prerelease software for invited U.S. testers age 18 or older.

## Install

**[Install DEMITROMI Founder Preview 0.1.1](DEMITROMI.appinstaller)**

If your browser downloads `DEMITROMI.appinstaller` instead of opening it automatically, open the downloaded file and choose **Install** in Windows App Installer.

Windows should handle installation through its normal trusted application installation experience. You should not need PowerShell, Developer Mode, Visual Studio, an SDK, repository access, or manual certificate installation.

The release package is signed by Michael Dimitrov using Microsoft Artifact Signing. Windows App Installer is configured to check this DEMITROMI update channel when the app launches.

## Privacy

Compose document processing is local to the PC. DEMITROMI does not intentionally upload document contents to a DEMITROMI server and does not enable behavioral analytics by default in this preview.

Review [Privacy Notice](PRIVACY.md) and [Founder Preview Terms](TERMS.md) before use.
